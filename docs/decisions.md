| D-026 | 2026-10-03 | **Hymnal: numbers belong to books; tunes carry the media; per-item access.** Hymns have no number of their own — `hymn_numbers` links a hymn to a **book** (`hymn_books`: code, name, country) with that book's number (text, so "246a" works), unique per book; the reader's country is listed first. Seeded books: **NCH** (New Catholic Hymnal, 2021) and **CH** (the older Ghana Catholic Hymnal), both of the Catholic Bishops' Conference of Ghana. Search accepts a number ("56"), a book and number ("NCH 56"), or words from the title, first line or lyrics (full-text). Tags hold seasons and occasions. A hymn has **one or more tunes** (one default); each tune has **media**: recordings (labelled Piano, Choir…, one default), MIDI, staff PDF, sol-fa PDF, and YouTube / YouTube Music links. Files go to object storage through presigned PUT/GET URLs (media module); the API checks type and size and never receives the binary. Every item has an **access level**: default FREE for MIDI and the default recording, SUBSCRIBER for notation, extra recordings and YouTube links; Super-Admins can change it. A platform switch `HYMNAL_PAYWALL` (off) keeps everything open until **personal (listener) subscriptions** exist — those, and playlists, come later. YouTube links play in a visible embedded player (YouTube's terms forbid audio-only playback); background audio comes only from uploaded recordings. Each hymn records its **source/permission**: the seed holds public-domain texts only; hymnal arrangements and scores need the publisher's permission before upload. The same media module now stores **saint portraits**. | functionality §3.6 · blueprint §7 · todo P5.4 |
| D-025 | 2026-10-03 | **Saints: fixed feasts, ranked saint of the day, original biographies.** `saints` holds each saint's fixed feast (month/day, General Roman Calendar), rank (solemnity → commemoration), title, one-line summary, patronage, born/died, biography paragraphs, source and an optional image key. The saint of the day is the highest-ranked published saint on the reader's local date (`GET /api/public/saints/today?date=`); others on the same day are listed with it, and days with no entry return none. Seeded biographies are short summaries written for Ecclesios (not copied), so they can stay in production; Super-Admins add or edit saints with `PUT /api/platform/saints/:slug` and can unpublish. Portraits arrive with the media module (Phase 5.4); until then a medal with initials is shown. | functionality §3.3 · todo P5.3 |
